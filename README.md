# SO.GL — сайт фотобудки

Одностраничный сайт без сборщика и зависимостей: HTML, CSS и JavaScript. Его можно разместить на любом статическом хостинге.

## Локальный запуск

Из этой папки:

```bash
python3 -m http.server 8080
```

Затем открыть <http://localhost:8080>. Не рекомендуется проверять страницу через `file://`: браузер может ограничивать видео и буфер обмена.

## Основные настройки

Все часто меняемые значения находятся в самом начале [`app.js`](app.js), в объекте `SITE_CONFIG`.

### Цены и скидки

```js
pricing: {
    firstHour: 3000,
    additionalHour: 2000,
    firstHourDiscount: 0,
    additionalHourDiscount: 0,
    minHours: 1,
    maxHours: 8,
    defaultHours: 2
}
```

Скидки задаются в рублях. Например, `firstHourDiscount: 500` делает первый час дешевле на 500 ₽. Если обе скидки равны `0`, плашка акции, старые цены и зачёркнутая итоговая сумма автоматически скрываются.

### Контакты

```js
contacts: {
    telegram: "https://t.me/username",
    vk: "https://vk.me/community_id",
    phoneHref: "tel:+79990000000",
    phoneLabel: "+7 999 000-00-00"
}
```

Пока значения пустые, кнопка сформирует и скопирует запрос, но не откроет мессенджер. Перед публикацией нужно заполнить все четыре поля.

### Видео

Положить оптимизированные файлы в `assets`, например `hero.mp4` и `bot.mp4`, затем указать:

```js
media: {
    heroVideo: "assets/hero.mp4",
    botVideo: "assets/bot.mp4"
}
```

- Главное видео рассчитано на вертикальную пропорцию примерно 4:5.
- Видео бота — на вертикальную пропорцию 9:16.
- Для быстрой загрузки желательно использовать MP4 (H.264), убрать звуковую дорожку и не делать файл тяжелее необходимого.
- Пока пути пустые, отображаются SVG-постеры из `assets`.

## Замена временных материалов

- Логотип: заменить `assets/logo-placeholder.svg` или поменять путь в `index.html`.
- Постеры видео: `assets/hero-video-poster.svg` и `assets/bot-video-poster.svg`.
- Галерея: заменить содержимое нужного `.gallery-slot` в `index.html` на `<img src="assets/имя-файла.jpg" alt="...">`. Сетка уже задаёт пропорции и обрезку.
- Перед публикацией стоит добавить растровую картинку 1200×630 для `og:image`, когда появятся реальные фотографии.

## Форма бронирования

Сайт не отправляет данные на сервер. Он формирует аккуратный текст запроса, копирует его в буфер обмена и открывает выбранный Telegram- или VK-чат. Это намеренно: посетитель не теряет контроль над сообщением, а сайту пока не нужен отдельный бэкенд и обработка персональных данных.

Условия оплаты сформулированы нейтрально: порядок оплаты определяется договором. Когда будет принято точное решение, текст можно обновить в FAQ.
