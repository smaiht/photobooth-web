# SO.GL — сайт фотобудки

https://github.com/user-attachments/assets/d3326474-8245-40b8-9bb8-931df9025145

Одностраничный сайт без сборщика и зависимостей: HTML, CSS и JavaScript. Его можно разместить на любом статическом хостинге.

## Локальный запуск

Из этой папки:

```bash
python3 -m http.server 8080
```

Затем открыть <http://localhost:8080>. Не рекомендуется проверять страницу через `file://`: браузер может ограничивать загрузку видео.

## Деплой на so.gl

Из корня проекта запустить:

```bash
./deploy.sh
# или: sh deploy.sh
```

Настройки сервера находятся в начале `deploy.sh`. Скрипт синхронизирует публичные файлы через rsync; лишние файлы на сервере удаляются, резервные копии не создаются. Исходный HTTP-конфиг лежит в `deploy/nginx-so.gl.conf`; Nginx и HTTPS на сервере настраиваются один раз и дальше не требуют действий при обычном обновлении сайта.

Для первого запуска на новом сервере используется отдельный скрипт:

```bash
./first_deploy.sh
```

Адрес сервера, SSH-пользователь, порт, веб-каталог и `CERTBOT_EMAIL` находятся в начале `first_deploy.sh`; те же настройки сервера находятся в начале `deploy.sh`. Email можно оставить пустым. Скрипт подключает конфигурацию Nginx, выпускает сертификат Let’s Encrypt для `so.gl` и `www.so.gl`, включает редирект на HTTPS, а затем запускает обычный деплой.

### Версия локальных ассетов

CSS, JavaScript, постеры и изображения подключены в `index.html` с параметром `?v=20260728-1`. Во время деплоя скрипт автоматически заменяет все значения `?v=` в опубликованных HTML, CSS и JavaScript на единый UTC-таймстемп. Локальные файлы при этом не меняются, а браузер получает свежую версию ассетов после каждой публикации.

## Основные настройки

Все часто меняемые значения находятся в самом начале [`app.js`](app.js), в объекте `SITE_CONFIG`.

### Цены и скидки

```js
pricing: {
    firstHour: 3000,
    additionalHour: 2000,
    firstHourDiscount: 0,
    additionalHourDiscount: 0,
    minHours: 1,
    maxHours: 8,
    defaultHours: 2
}
```

Скидки задаются в рублях. Например, `firstHourDiscount: 500` делает первый час дешевле на 500 ₽. Цена и старая зачёркнутая цена обновляются одновременно в hero и в блоке стоимости. Если обе скидки равны `0`, плашка акции и все старые цены автоматически скрываются.

### Контакты

```js
contacts: {
    telegram: "https://t.me/username",
    vk: "https://vk.me/community_id",
    max: "https://max.ru/...",
    phoneHref: "tel:+79990000000",
    phoneLabel: "+7 999 000-00-00"
}
```

Пока значения пустые, ссылки ведут к блоку контактов и показывают подсказку о настройке. Перед публикацией нужно заполнить все пять полей.

После заполнения номер телефона и ссылки на мессенджеры также автоматически добавляются в структурированные данные `LocalBusiness`.

### Видео

Главное видео подключено прямо в `index.html`, чтобы браузер увидел его во время разбора HTML, не дожидаясь JavaScript. Для него используются MP4 `assets/video/pb1-web-720p.mp4` и постер `assets/hero-video-poster.webp`.

Исходный ролик сохранён локально в `source-assets/video` и не публикуется. Публичная версия подготовлена в H.264, без аудиодорожки, с быстрым стартом и кадром 4:5 под hero-карточку. При замене ролика нужно обновить MP4, постер, размеры `width`/`height` и значение `?rev=` в трёх hero-URL внутри `index.html`.

Необязательное видео демонстрации бота по-прежнему настраивается в `app.js`:

```js
media: {
    botVideo: "assets/bot.mp4"
}
```

- Демонстрация бота — на горизонтальную пропорцию 4:3.
- Для быстрой загрузки используйте MP4 (H.264/yuv420p), убирайте звуковую дорожку и размещайте MP4 metadata в начале файла (`faststart`).
- Пока путь видео бота пустой, отображается SVG-постер из `assets`.

Версионированные CSS, JavaScript, изображения и видео получают в Nginx `Cache-Control: public, max-age=31536000, immutable`. HTML отдаётся с `Cache-Control: no-cache`. Версия hero-медиа меняется вручную через `?rev=`, поэтому ролик не скачивается заново при каждом обычном деплое.

## Замена временных материалов

- Логотип: заменить `assets/logo-placeholder.svg` или поменять путь в `index.html`.
- Постеры видео: `assets/hero-video-poster.webp` и `assets/bot-video-poster.svg`; схема готового принта — `assets/bot-print-output.svg`.
- Галерея: заменить содержимое нужного `.gallery-slot` в `index.html` на `<img src="assets/имя-файла.jpg" alt="...">`. Сетка уже задаёт пропорции и обрезку.
- Перед публикацией стоит добавить растровую картинку 1200×630 для `og:image`, когда появятся реальные фотографии.

## Блок контактов

Формы бронирования на сайте нет. Все кнопки «Связаться» и «Уточнить дату» ведут к блоку прямых ссылок на телефон, Telegram, ВКонтакте и MAX из `SITE_CONFIG`.

Условия оплаты сформулированы нейтрально: порядок оплаты определяется договором. Когда будет принято точное решение, текст можно обновить в FAQ.
